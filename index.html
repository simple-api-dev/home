Why it exists

  

    Most "todo app" tutorials either have no backend at all or lean on a vendor SDK, so they never
    show how login, tokens and per-user data work. SimpleApi gives you plain REST endpoints you can
    call from any language or framework, with the authentication part included.
  

  
    
    
  • Plain REST and JSON. No SDK or vendor account needed. Use fetch, axios, curl, or whatever you are learning.
    • 
    
  • Real authentication. Your app's users can register, log in and log out, and each gets a token.
    • 
    
  • Your own data. Everything you create is scoped to your API key, so other developers do not see it.
    • 
    
  • Documented. Every API has interactive Swagger docs and a Postman collection.
    •

After your first key

  
    
    
  1. Send the key with every request, as an APIKEY header or an apikey parameter.
    2. 
    
  2. Let your own users register and log in through the API. You get back a user token to send on later requests.
    3. 
    
  3. Need a key for another API, or want to turn one off? Use the key manager. Each key works only for the API it was issued for.
    4. 
  






  
Good to know

  
    
    
  • The free tier has limits. For example, Todos allows 100 todos per developer key and 25 per user.
    • 
    
  • This is a hobby-scale service meant for learning, so do not use it for production data or anything sensitive.
    • 
    
  • Each API's docs page has the full list of endpoints, and you can try calls right from the page.
